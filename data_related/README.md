# data_related

`data_related` 模块负责数据处理全链路：原始数据读取、样本预处理、数据集封装、批次加载、评价指标计算与数据集级操作，目标是将数据工程与训练流程解耦，提升训练复用性与可维护性。

## 子模块说明（详细）
- `criteria.py`：提供训练/验证评价指标函数，统一“预测值-标签值”输入范式，便于在 `Trainer` 中直接复用并统计指标历史。
- `data_transformer.py`：定义数据预处理抽象接口，负责把原始样本转换为模型可用输入（如归一化、维度变换、数据增强）。
- `storage_dloader.py`：定义存储读取流程与线程行为，负责把文件系统或外部存储中的数据读取为可进一步处理的样本对象。
- `datasets.py`：实现数据集容器与样本组织逻辑，管理样本索引、切片、预处理触发与按需读取。
- `selfdefined_ds.py`：面向业务侧的自定义数据集基类/模板，便于用户实现自己的读取规则、标签组织、展示与保存逻辑。
- `dataloader.py`：负责批次构造与数据迁移函数调用，把 `Dataset` 输出组织为训练迭代可直接消费的数据批。
- `ds_operation.py`：提供数据集级工具，如数据集切片、k 折拆分、归一化/逆归一化、数据加载器转换等。
- `prediction_wrapper.py`：封装预测阶段输入输出对接逻辑，降低推理流程与训练流程之间的耦合成本。
